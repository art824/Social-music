# Social Music

Um badge vestível e minimalista que mostra a capa do álbum que a pessoa está ouvindo. Projeto do fundador (estudante brasileiro).

**Comece por `00-comece-aqui/estado-do-projeto.md`.** Para falar de um assunto, abra só a pasta dele.

| Pasta | Assunto |
|---|---|
| `00-comece-aqui/` | Estado do projeto, mapa visual, decisões, como retomar |
| `1-ideia-e-mercado/` | A ideia, comprador, preço, concorrentes, processo "venture" |
| `2-produto-e-prototipo/` | Plano do protótipo, hardware, modelo 3D, testes |
| `3-legal-e-dinheiro/` | Certificação, país de venda, empresa, crowdfunding |
| `4-marketing-e-redes/` | Construir em público, idioma, nome |
| `5-brasil-e-apoio/` | Sebrae, Living Hub, instituições |

Cada pasta tem um `README.md` com: o que está decidido, o que está em aberto e onde ficam os detalhes.
