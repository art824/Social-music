# 2 Produto e protótipo

**Decidido pelo fundador:** só exibição (um grampo, um botão, uma luz); três modos; iPhone e Android; protótipo próprio para uso e conteúdo.
**Em aberto:** placa, LCD ou e-ink, fixação (clipe ou colar), onde imprimir.
**Estacionado:** firmware, app, modelo 3D com medidas reais.

- `prototipo-plano.md`: etapas, peças, custos e riscos (proposta do Claude, nada comprado).
- `pesquisa-produto-e-hardware.md`: como o produto pegaria os dados, placas, telas, bateria, ferramentas 3D.
- `cad/`: modelo 3D provisório que ninguém pediu (pode apagar).
- `tools/art_coverage.py`: teste de cobertura de capas de álbum.
